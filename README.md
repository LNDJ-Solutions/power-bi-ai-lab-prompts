## Tutorial: Modern Power BI KPI Cards with AI

The page at `tutorials/modern-power-bi-kpi-cards/` contains four exact prompts recovered from the creator's referenced conversation: three sequential ChatGPT/manual Power BI prompts and one Codex + Power BI MCP prompt. The manual chat route is distinct from the Codex/MCP route. Each prompt expands for reading and has a copy button.

The public path is <https://lndj-solutions.github.io/power-bi-ai-lab-prompts/tutorials/modern-power-bi-kpi-cards/>. The tutorial uses the requested title and URL path. GitHub Pages publication updates after the site files are committed and pushed to `main`.
